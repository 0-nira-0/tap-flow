# TapFlow

Landing page for TapFlow — an NFC product that lets you share contacts, links, and trigger automations with a single tap.

Built with React, TypeScript, Vite, and Tailwind CSS. Deployed on Vercel.

**Demo:** https://tap-flow-psi.vercel.app/
